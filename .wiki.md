# Project Summary
The project is focused on developing a premium B2B landing page for Sodium Thiosulfate, a chemical compound used in various industries such as water treatment, mining, pharmaceuticals, and textiles. The goal is to create a visually appealing and high-performing website that effectively markets Sodium Thiosulfate, showcasing its applications, specifications, and benefits while providing an inquiry form for potential customers.

# Project Module Description
The project consists of multiple modules, including:
- **Frontend**: User interface built with React, featuring components for navigation, hero section, product specifications, applications, and an inquiry form.
- **Backend**: API services for handling inquiries and data management.
- **Database**: Storage for inquiry submissions managed through Atoms Cloud.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Vite
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic
- **Database**: Atoms Cloud for inquiry storage

# Usage
To set up the project:
1. Install dependencies:
   - For the backend: `pip install -r app/backend/requirements.txt`
   - For the frontend: `pnpm install` in the `app/frontend` directory.
2. Build the frontend:
   - Run `pnpm run build` in the `app/frontend` directory.
3. Start the backend server:
   - Execute the command to start the backend service as per your setup.
