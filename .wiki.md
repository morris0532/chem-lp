# Project Summary
The project is focused on developing a premium B2B landing page for Sodium Thiosulfate, a chemical compound utilized in water treatment, mining, pharmaceuticals, and textiles. The aim is to create a visually appealing and high-performing website that effectively markets Sodium Thiosulfate, showcasing its applications, specifications, and benefits, while providing a user-friendly inquiry form for potential customers.

# Project Module Description
The project consists of multiple modules, including:
- **Frontend**: A pure frontend web application built with React, featuring components for navigation, hero section, product specifications, applications, and an inquiry form.
- **Inquiry Form**: Allows users to submit inquiries via WhatsApp or email, displaying a success message upon submission.

# Usage
To set up the project:
1. Install dependencies:
   - For the frontend: `pnpm install` in the `app/frontend` directory.
2. Build the frontend:
   - Run `pnpm run build` in the `app/frontend` directory.
